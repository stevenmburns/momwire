# Experimental features

Generated by `python scripts/feature_table.py` from `src/momwire/_features.py`,
`support/hierarchy.toml`, `standalone/momwire_razor2p.cpp` and the script's
own `CXX` table. Do not edit by hand: `tests/test_feature_table.py` fails
when this file is stale.

## Levels

A feature of reach N is certified on levels 1..N. **Stable** means reach ==
the deepest level, 9.

| level | id | description |
|---|---|---|
| 1 | `ak-linux-avx2` | antennaknobs on Linux, avx2 variant only: the hosted app |
| 2 | `ak-linux-sse2` | momwire Python on Linux with the sse2 variant (pre-AVX2 CPUs) |
| 3 | `ak-windows` | antennaknobs on Windows, avx2 and sse2 |
| 4 | `dropin-linux-windows` | the Python drop-in engine (NEC-2 / NEC-4.2 / NEC-5 dialects) on Linux and Windows, avx2 and sse2 |
| 5 | `macos` | antennaknobs and the Python drop-in engine (NEC-2 / NEC-4.2 / NEC-5 dialects) on macOS |
| 6 | `exe-nec5-bspline-razor-2p-windows` | the nec5-bspline and nec5-razor-2p executables on Windows, avx2 and sse2 |
| 7 | `exe-nec5-bspline-razor-2p-linux-macos` | the nec5-bspline and nec5-razor-2p executables on Linux and macOS |
| 8 | `exe-nec42-bspline` | the nec42-bspline executable, all platforms |
| 9 (stable) | `exe-nec42-sinusoidal` | the nec42-sinusoidal executable, all platforms |

**Promotion** is raising a feature's `reach`, one level at a time, in its own
PR that selects the new levels' jobs; it is Steve's call. **Default-on** is a
separate promotion (`default`), also Steve's, and independent of reach.

## Columns

- **kind**: outside its reach, `python` runs and is stamped uncertified on
  printout line 2; `native` refuses with `FeatureNotCertified`.
- **drift**: the declared bound on |dZin|/|Zin|, on against off.
- **offer**: whether a front end exposes the switch per request.
- **executables**: the levels (of 6-9) where the standalone executables
  run it, from `EXE_FEATURES`; any other feature turned on makes them exit 2.
- **C++**: `exe route` is a switch of the C++ route the executables build;
  `extension only` is C++ in the Python extension alone; `none` is Python
  only.
